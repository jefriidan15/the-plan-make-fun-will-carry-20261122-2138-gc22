A make.fun entry for the competition "The plan make.fun will carry out in public".

`main.ts` (Node 22, dependency-free) writes one plan text to `/output/entry.txt`:
a plan an AI agent can carry out itself to turn $100 into the most money in
30 days — build ready-made lead-gen sites for local roofers, sell them for
$299 each by cold email, starting on day one.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The output is deterministic: two runs produce byte-identical text (278 Unicode
code points, within the 1–280 gate). No network, no clock, no environment
dependence.
